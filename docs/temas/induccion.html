Inducción matemática

Método de demostración para proposiciones definidas sobre los números naturales

Objetivo

Comprender la inducción matemática como una técnica para demostrar afirmaciones que dependen de un número natural \(n\). La meta es reconocer sus partes, escribirlas con claridad y aplicarlas en fórmulas, divisibilidad y desigualdades.

Idea central

Verificar muchos casos particulares puede sugerir una regularidad, pero no demuestra una afirmación general. Aunque una propiedad funcione para \(n=1,2,3,\ldots,1000\), todavía podría fallar después.

En inducción trabajamos con una proposición \(P(n)\), es decir, un enunciado matemático que depende de \(n\). Por ejemplo:

\[ P(n):\quad 1+3+5+\cdots+(2n-1)=n^2. \]

La idea es verificar el primer caso y demostrar que cada caso verdadero garantiza el siguiente. Así se justifica toda la cadena.

Principio de inducción matemática

NotaPrincipio de inducción matemática

Sea \(P(n)\) una proposición definida para los números naturales.

Si se cumplen estas dos condiciones:

  1. \(P(1)\) es verdadera.
  2. Para todo \(n \in \mathbb{N}\), si \(P(n)\) es verdadera, entonces \(P(n+1)\) es verdadera.

Entonces \(P(n)\) es verdadera para todo \(n \in \mathbb{N}\).

El caso base no siempre empieza en \(1\). Si la afirmación solo se plantea para \(n \geq 5\), se prueba primero \(P(5)\) y luego se demuestra que \(P(n) \Rightarrow P(n+1)\) para todo \(n \geq 5\).

Estructura de una demostración por inducción

  1. Definir \(P(n)\): escribir con precisión qué se desea demostrar.
  2. Caso base: verificar el primer valor, por ejemplo \(n=1\) o \(n=5\).
  3. Hipótesis inductiva: suponer que \(P(n)\) es verdadera para un \(n \in \mathbb{N}\).
  4. Paso inductivo: usar esa hipótesis para demostrar \(P(n+1)\).
  5. Conclusión: declarar que, por inducción, \(P(n)\) es verdadera en todo el dominio indicado.
TipIdea importante

En el paso inductivo no se demuestra directamente que \(P(n)\) sea verdadera. Se demuestra la implicación:

\[ P(n) \Rightarrow P(n+1). \]

Ejemplo 1: suma de los primeros números impares

Demostremos que, para todo \(n \in \mathbb{N}\),

\[ 1+3+5+\cdots+(2n-1)=n^2. \]

Sea

\[ P(n):\quad \sum_{i=1}^{n}(2i-1)=n^2. \]

Caso base. Para \(n=1\):

\[ 1=1^2. \]

Luego \(P(1)\) es verdadera.

Hipótesis inductiva. Supongamos que \(P(n)\) es verdadera:

\[ 1+3+5+\cdots+(2n-1)=n^2. \]

Paso inductivo. Queremos probar \(P(n+1)\):

\[ 1+3+5+\cdots+(2n-1)+\bigl(2(n+1)-1\bigr)=(n+1)^2. \]

Usamos la hipótesis inductiva:

\[ \begin{aligned} 1+3+\cdots+(2n-1)+\bigl(2(n+1)-1\bigr) &= n^2+(2n+1)\\ &= n^2+2n+1\\ &= (n+1)^2. \end{aligned} \]

Conclusión. Por inducción matemática,

\[ 1+3+5+\cdots+(2n-1)=n^2 \]

para todo \(n \in \mathbb{N}\).

Ejemplo 2: suma de los primeros números naturales

Demostremos que, para todo \(n \in \mathbb{N}\),

\[ 1+2+3+\cdots+n=\frac{n(n+1)}{2}. \]

Sea

\[ P(n):\quad \sum_{i=1}^{n} i=\frac{n(n+1)}{2}. \]

Caso base. Para \(n=1\):

\[ 1=\frac{1(1+1)}{2}=1. \]

Luego \(P(1)\) es verdadera.

Hipótesis inductiva. Supongamos que \(P(n)\) es verdadera:

\[ 1+2+3+\cdots+n=\frac{n(n+1)}{2}. \]

Paso inductivo. Debemos demostrar \(P(n+1)\):

\[ 1+2+\cdots+n+(n+1)=\frac{(n+1)(n+2)}{2}. \]

Usando la hipótesis inductiva:

\[ \begin{aligned} 1+2+\cdots+n+(n+1) &= \frac{n(n+1)}{2}+(n+1)\\ &= (n+1)\left(\frac{n}{2}+1\right)\\ &= (n+1)\left(\frac{n+2}{2}\right)\\ &= \frac{(n+1)(n+2)}{2}. \end{aligned} \]

Conclusión. Por inducción,

\[ 1+2+3+\cdots+n=\frac{n(n+1)}{2} \]

para todo \(n \in \mathbb{N}\).

Ejemplo 3: una desigualdad desde cierto valor inicial

Demostremos que

\[ 4n<2^n \]

para todo \(n \geq 5\).

Sea

\[ P(n):\quad 4n<2^n. \]

Caso base. Para \(n=5\):

\[ 4\cdot 5=20<32=2^5. \]

Luego \(P(5)\) es verdadera.

Hipótesis inductiva. Supongamos que \(P(n)\) es verdadera para algún \(n\geq 5\):

\[ 4n<2^n. \]

Paso inductivo. Queremos demostrar \(P(n+1)\):

\[ 4(n+1)<2^{n+1}. \]

Como \(n\geq 5\), se tiene \(4<4n\). Además, por la hipótesis inductiva, \(4n<2^n\). Por lo tanto, \(4<2^n\). Entonces:

\[ \begin{aligned} 4(n+1) &=4n+4\\ &<2^n+4\\ &<2^n+2^n\\ &=2\cdot 2^n\\ &=2^{n+1}. \end{aligned} \]

Conclusión. Por inducción matemática,

\[ 4n<2^n \]

para todo \(n\geq 5\).

Errores comunes

AdvertenciaAntes de cerrar una inducción, revisa esto
  • Olvidar el caso base.
  • Asumir directamente lo que se quiere demostrar.
  • No usar la hipótesis inductiva en el paso inductivo.
  • Confundir \(P(n)\) con \(P(n+1)\).
  • No revisar desde qué valor inicial comienza la afirmación.

Ejercicios

Ejercicios con solución

Ejercicio 1

Demuestra por inducción que, para todo \(n \in \mathbb{N}\),

\[ 2+4+6+\cdots+2n=n(n+1). \]

Solución.

Sea

\[ P(n):\quad \sum_{i=1}^{n}2i=n(n+1). \]

Caso base. Para \(n=1\), \(2=1(1+1)=2\).

Hipótesis inductiva. Supongamos que

\[ 2+4+\cdots+2n=n(n+1). \]

Paso inductivo.

\[ \begin{aligned} 2+4+\cdots+2n+2(n+1) &=n(n+1)+2(n+1)\\ &=(n+1)(n+2). \end{aligned} \]

Esto es \(P(n+1)\), pues

\[ (n+1)\bigl((n+1)+1\bigr)=(n+1)(n+2). \]

Por inducción, la fórmula es válida para todo \(n \in \mathbb{N}\).

Ejercicio 2

Demuestra que \(5^n-1\) es divisible por \(4\) para todo \(n \in \mathbb{N}\).

Solución.

Sea

\[ P(n):\quad 4 \mid (5^n-1). \]

Caso base. Para \(n=1\), \(5^1-1=4\), que es divisible por \(4\).

Hipótesis inductiva. Supongamos que \(4 \mid (5^n-1)\). Entonces existe un entero \(m\) tal que

\[ 5^n-1=4m. \]

Paso inductivo.

\[ \begin{aligned} 5^{n+1}-1 &=5\cdot 5^n-1\\ &=5(5^n-1)+4\\ &=5(4m)+4\\ &=4(5m+1). \end{aligned} \]

Por lo tanto, \(4 \mid (5^{n+1}-1)\). Por inducción, \(5^n-1\) es divisible por \(4\) para todo \(n \in \mathbb{N}\).

Ejercicio 3

Demuestra que, para todo \(n\geq 4\),

\[ n^2\leq 2^n. \]

Solución.

Sea

\[ P(n):\quad n^2\leq 2^n,\qquad n\geq 4. \]

Caso base. Para \(n=4\):

\[ 4^2=16=2^4. \]

Hipótesis inductiva. Supongamos que, para algún \(n\geq 4\),

\[ n^2\leq 2^n. \]

Paso inductivo. Queremos probar que \((n+1)^2\leq 2^{n+1}\). Como \(n\geq 4\), se cumple \((n+1)^2\leq 2n^2\), pues esta desigualdad equivale a \(n^2-2n-1\geq 0\).

\[ (n+1)^2\leq 2n^2. \]

Usando la hipótesis inductiva:

\[ (n+1)^2\leq 2n^2\leq 2\cdot 2^n=2^{n+1}. \]

Por inducción, \(n^2\leq 2^n\) para todo \(n\geq 4\).

Sea la sucesión definida por \(a_1=2\) y

\[ a_{n+1}=2a_n+1. \]

Demuestra que

\[ a_n=3\cdot 2^{n-1}-1 \]

para todo \(n \in \mathbb{N}\).

Ideas clave

  • La inducción sirve para demostrar proposiciones \(P(n)\) sobre números naturales.
  • El caso base inicia la cadena de implicaciones.
  • La hipótesis inductiva es una suposición temporal: se usa para probar el siguiente caso.
  • El paso inductivo debe demostrar \(P(n+1)\), no repetir \(P(n)\).
  • Si la afirmación comienza en \(n\geq a\), el caso base debe ser \(P(a)\).
