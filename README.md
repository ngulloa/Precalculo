# Sobre el sitio
Sitio web educativo que reúne un compendio introductorio de precálculo, pensado para estudiantes que buscan reforzar sus conocimientos de forma clara, rápida y accesible. La plataforma ofrece explicaciones breves, visualizaciones, actividades interactivas y ejercicios prácticos para apoyar el estudio autónomo y hacer el aprendizaje más dinámico.
